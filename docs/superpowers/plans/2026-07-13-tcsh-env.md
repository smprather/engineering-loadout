# tcsh Environment Implementation Plan

> **SUPERSEDED 2026-08-08.** This document's core premise -- that the tcsh env
> is a one-time port that does NOT track `envs/bash/`, justified by a near-zero
> expected user count -- was reversed by the owner. The EE community this project
> serves is ~90% tcsh, and `envs/tcsh/` now tracks the bash env. Kept as a record
> of what was decided in July 2026; do not follow its "does not track" guidance.
> See `docs/HANDOFF.md` -> "POLICY REVERSAL: tcsh now tracks bash/zsh".

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Give a tcsh user the loadout's PATH, config variables, aliases, prompt, and layer chain — silently, on any machine, without crashing or printing a single warning.

**Architecture:** `envs/tcsh/` mirrors `envs/bash/`'s shape (entry point + `global/` + five user-created override layers). An `env-tcsh` package installs it to `~/.config/tcsh` and links `~/.tcshrc` / `~/.cshrc`. Everything is guarded so an absent tool or an absent loadout install produces no output.

**Tech Stack:** tcsh (csh syntax), Python 3.14 (`loadout_main.py`), POSIX sh (tests).

Spec: `docs/superpowers/specs/2026-07-13-tcsh-env-design.md`

## Global Constraints

- **Silence is the acceptance criterion.** Startup must produce **empty stderr** and exit 0 — on a fresh HOME, on a HOME with no loadout tools installed, login and interactive. A warning is a bug. A missing feature is not.
- **This does NOT track `envs/bash/`.** No drift test, no generator, no "and update tcsh too" coupling. It is a deliberate one-time snapshot; say so in the files.
- **csh has no functions.** Do not attempt to emulate them with `eval` gymnastics. Port `path_*` and `source_if_exists` as aliases; leave the other 26 out and document that.
- **Guard everything.** Every `source` behind `if (-r ...)`, every tool alias behind `where`, every env var behind a `-d` test. tcsh's `-e`-less error behavior means an unguarded reference prints to stderr and keeps going — which is exactly the noise we are forbidding.
- **csh quoting is a minefield.** `!` must be escaped (`\!*`) inside aliases; `'` and `"` do not behave as in sh. Verify every alias by running a real tcsh, never by reading it.
- tcsh is **not** bundled — it is the site's shell. `env-tcsh` ships config only.
- Registry changes require `./loadout completion bash > envs/bash/global/completions/loadout.bash` and `build/gen-content-manifest` (a `packages.json` edit invalidates `.content-manifest`).

- [ ] **Step 1: Write `envs/tcsh/tcshrc` — the dispatcher**

Two passes over the six layers, mirroring bash. Every source guarded:

```csh
#!/bin/tcsh
# Loadout tcsh entry point.  ~/.tcshrc and ~/.cshrc link here.
#
# NOTE: this environment is a deliberate ONE-TIME port of the bash environment.
# It does not track envs/bash/ and there is no drift test between them. csh has no
# functions, so most of envs/bash/functions.sh is intentionally absent -- see
# envs/tcsh/README.md.  Do not "fix" that.

set _loadout_tcsh_dir = "$HOME/.config/tcsh"

# Pass 1: config (LOADOUT_CFG_*) for every layer, lowest first.
foreach _l (global corp site team project user)
    if (-r "$_loadout_tcsh_dir/$_l/config.csh") then
        source "$_loadout_tcsh_dir/$_l/config.csh"
    endif
end

# Pass 2: the shells themselves.
foreach _l (global corp site team project user)
    if (-r "$_loadout_tcsh_dir/$_l/tcshrc") then
        source "$_loadout_tcsh_dir/$_l/tcshrc"
    endif
end

unset _l
unset _loadout_tcsh_dir
```

- [ ] **Step 2: Write `envs/tcsh/global/config.csh`**

A hand-written **snapshot** of the `LOADOUT_CFG_*` variables that mean something in tcsh. Header must say it is a snapshot and is not synced.

```csh
# Loadout tcsh config -- LOADOUT_CFG_* preferences.
#
# SNAPSHOT, NOT A MIRROR. These are hand-maintained and deliberately NOT generated
# from envs/bash/global/config.sh. There is no drift test: the tcsh environment is a
# one-time best-effort port and does not track the bash env. If bash gains a config
# var, tcsh does not automatically need it.
#
# Override any of these in ~/.config/tcsh/user/config.csh.

if (! $?LOADOUT_CFG_SHARED_PREFIX)       setenv LOADOUT_CFG_SHARED_PREFIX ""
if (! $?LOADOUT_CFG_PREFERRED_LS)        setenv LOADOUT_CFG_PREFERRED_LS eza
if (! $?LOADOUT_CFG_PREFERRED_VI)        setenv LOADOUT_CFG_PREFERRED_VI nvim
if (! $?LOADOUT_CFG_PREFERRED_CAT)       setenv LOADOUT_CFG_PREFERRED_CAT bat
if (! $?LOADOUT_CFG_ENABLE_GRC)          setenv LOADOUT_CFG_ENABLE_GRC 1
if (! $?LOADOUT_CFG_PROMPT_INCLUDE_HOST) setenv LOADOUT_CFG_PROMPT_INCLUDE_HOST 0
```

- [ ] **Step 3: Write `envs/tcsh/global/tcshrc` — PATH, env, prompt**

Mirror the bash PATH resolution (shared prefix first, then `~/.local/bin`), terminfo, and the GUI env vars. Every path guarded with `-d`. The prompt is a `precmd` alias with **at most one `git` fork**, guarded on `git` existing.

```csh
# Loadout tcsh: PATH, environment, prompt.  Snapshot of the bash env; not synced.

# ---- PATH (only dirs that exist; never announce anything) -------------------
set _lprefix = "$HOME/.local"
if ($?LOADOUT_CFG_SHARED_PREFIX) then
    if ("$LOADOUT_CFG_SHARED_PREFIX" != "") set _lprefix = "$LOADOUT_CFG_SHARED_PREFIX"
endif

foreach _d ("$_lprefix/bin" "$HOME/.local/bin" "$HOME/.cargo/bin" "$HOME/go/bin")
    if (-d "$_d") then
        # prepend, without duplicating
        set path = ($_d $path:q)
    endif
end
# de-dup $path in place (csh has no assoc arrays; this is the idiomatic pass)
set _seen = ()
set _newpath = ()
foreach _d ($path:q)
    if (" $_seen " !~ "* $_d *") then
        set _newpath = ($_newpath:q $_d)
        set _seen = ($_seen:q $_d)
    endif
end
set path = ($_newpath:q)
unset _seen _newpath _d

# ---- terminfo: ncurses does not search ~/.local/share/terminfo by default ----
if (-d "$_lprefix/share/terminfo") then
    if ($?TERMINFO_DIRS) then
        setenv TERMINFO_DIRS "$_lprefix/share/terminfo:${TERMINFO_DIRS}"
    else
        setenv TERMINFO_DIRS "$_lprefix/share/terminfo"
    endif
endif

# ---- GUI/runtime helpers (only when present) --------------------------------
if (-d "$_lprefix/lib/girepository-1.0") setenv GI_TYPELIB_PATH "$_lprefix/lib/girepository-1.0"
if (-f "$_lprefix/lib64/libqxcb.so")     setenv QT_QPA_PLATFORM_PLUGIN_PATH "$_lprefix/lib64"

# ---- interactive-only below --------------------------------------------------
if (! $?prompt) then
    unset _lprefix
    exit 0
endif

set history = 10000
set savehist = (10000 merge)
set autolist
set color
set colorcat

# ---- prompt: cwd + git branch.  At most ONE git fork per prompt. -------------
# precmd runs before every prompt; a slow prompt is the usability turn-off this
# environment exists to avoid. Resolve `git` once, here, not per prompt.
if (-X git) then
    alias precmd 'set _br = "`git symbolic-ref --short HEAD >& /dev/null && git symbolic-ref --short HEAD`" ; if ("$_br" != "") then ; set prompt = "%B%~%b (${_br}) %# " ; else ; set prompt = "%B%~%b %# " ; endif'
else
    set prompt = "%B%~%b %# "
endif

source "$HOME/.config/tcsh/global/aliases.csh"

unset _lprefix
```

Note for the implementer: the `precmd` one-liner above is the single most likely thing in this plan to be subtly wrong (csh quoting + `;` separators + backticks). **Test it in a real tcsh and iterate until it is silent and correct**, including in a non-git directory and in a directory with a detached HEAD. If it cannot be made clean as an alias, define the prompt without the branch rather than shipping something noisy.

- [ ] **Step 4: Write `envs/tcsh/global/aliases.csh`**

Port only what carries the daily-driver feel, and **define a tool alias only if the tool exists**, so no alias ever resolves to a missing binary:

```csh
# Loadout tcsh aliases. Snapshot of envs/bash/global/aliases.sh; not synced.
# Aliases that depended on bash FUNCTIONS (the env-var-driven `ls` wrapper, the
# custom `cd`) are re-expressed directly here or omitted -- csh has no functions.

# navigation
alias b      'cd ..'
alias bb     'cd ../..'
alias bbb    'cd ../../..'
alias bbbb   'cd ../../../..'
alias bbbbb  'cd ../../../../..'
alias cd-    'cd -'

# listing -- pick the best available ls once, at startup
if (-X eza) then
    alias ll 'eza -l'
    alias la 'eza -la'
    alias lh 'eza -lh'
else
    alias ll 'ls -l'
    alias la 'ls -la'
    alias lh 'ls -lh'
endif

# search
if (-X rg) then
    alias g 'rg --smart-case --hidden --no-ignore'
else
    alias g 'grep -r'
endif
if (-X fd) then
    alias f 'fd --unrestricted --full-path'
else
    alias f 'find . -name'
endif

# editor / pager
alias vi 'nvim'
if (-X bat) alias cat 'bat --paging=never'

# git
alias gs 'git status'
alias gc 'git commit'
alias gp 'git push'
alias gd 'git diff'
alias ga 'git add -A ; git status'

# misc
alias h  'history | grep'
alias x  'chmod +x'
alias rp 'realpath'
alias t  'exec tcsh'
alias w  'where'

# path helpers -- the only functions from envs/bash/functions.sh that survive the
# port (they only manipulate $path, which csh has natively).
alias path_prepend 'set path = (\!:1 $path:q)'
alias path_append  'set path = ($path:q \!:1)'
```

`vi` should honor `$LOADOUT_CFG_PREFERRED_VI` if that is expressible cleanly; if not, alias to `nvim` when present and `vim` otherwise — do not ship an alias to a binary that is not there.

- [ ] **Step 2: The handler**

Same non-destructive shape as `_install_env_st` — the generic handler's `sync_dir(delete=True)` would wipe the user's own layers.

```python
def _install_env_tcsh(repo_dir, home):
    """Install the tcsh config layers and point ~/.tcshrc / ~/.cshrc at them.

    global/ is loadout-owned and synced with delete semantics; the five override
    layers are user-created and must survive a reinstall, so this cannot use the
    generic directory handler (install_path() on a dir syncs with delete=True).
    """
    src = os.path.join(repo_dir, "envs", "tcsh")
    if not os.path.isdir(src):
        return
    tcsh_dir = os.path.join(home, ".config", "tcsh")
    if os.path.islink(tcsh_dir):
        os.unlink(tcsh_dir)
    ensure_dir(tcsh_dir, "tcsh config")
    install_path(os.path.join(src, "global"), os.path.join(tcsh_dir, "global"), False)
    install_path(os.path.join(src, "tcshrc"), os.path.join(tcsh_dir, "tcshrc"), False)
    for layer in ("corp", "site", "team", "project", "user"):
        ensure_dir(os.path.join(tcsh_dir, layer), "tcsh config layer")
    for entrypoint in (".tcshrc", ".cshrc"):
        dest = os.path.join(home, entrypoint)
        remove_if_exists(dest)
        lns(os.path.join(tcsh_dir, "tcshrc"), dest, verbose=True)
```

Register in `ENV_HANDLERS` **and** `ENV_INSTALL_ORDER` (the `@envs` group path dispatches through the latter).

- [ ] **Step 1: Write the test**

Skips cleanly without tcsh (the dev box has none); runs for real in the Tier 3 container.

```sh
#!/bin/sh
# env-tcsh: installs, links the entrypoints, and -- the headline requirement --
# starts SILENTLY: empty stderr, exit 0, on a machine with no loadout tools.
set -eu
REPO="$(cd "$(dirname "$0")/.." && pwd)"

if ! command -v tcsh >/dev/null 2>&1; then
    echo "SKIP: native tcsh smoke (no tcsh interpreter; Tier 3 installs tcsh)"
    exit 0
fi

TMPHOME="$(mktemp -d /tmp/loadout-env-tcsh.XXXXXX)"
trap 'rm -rf "$TMPHOME"' EXIT
fail() { echo "FAIL: $*" >&2; exit 1; }

HOME="$TMPHOME" "$REPO/loadout" install env-tcsh --no-backup >/dev/null

[ -e "$TMPHOME/.tcshrc" ] || fail ".tcshrc not linked"
[ -e "$TMPHOME/.cshrc" ] || fail ".cshrc not linked"
[ -f "$TMPHOME/.config/tcsh/global/tcshrc" ] || fail "global layer not installed"

# THE headline test: env-only HOME (no loadout tools at all) must start silently.
err="$TMPHOME/stderr.txt"
HOME="$TMPHOME" tcsh -i -c 'exit 0' 2>"$err" || fail "interactive tcsh exited non-zero"
[ ! -s "$err" ] || fail "interactive tcsh wrote to stderr:
$(cat "$err")"

HOME="$TMPHOME" tcsh -l -c 'exit 0' 2>"$err" || fail "login tcsh exited non-zero"
[ ! -s "$err" ] || fail "login tcsh wrote to stderr:
$(cat "$err")"

# The env actually landed.
out=$(HOME="$TMPHOME" tcsh -i -c 'echo $LOADOUT_CFG_PREFERRED_VI; alias b' 2>/dev/null)
echo "$out" | grep -q "nvim" || fail "LOADOUT_CFG_* not set in tcsh"
echo "$out" | grep -q "cd .." || fail "aliases not loaded"

# Reinstall must not clobber a user layer (the env-st lesson).
echo 'setenv MYVAR 1' > "$TMPHOME/.config/tcsh/user/config.csh"
HOME="$TMPHOME" "$REPO/loadout" install env-tcsh --no-backup >/dev/null
[ -f "$TMPHOME/.config/tcsh/user/config.csh" ] || fail "reinstall deleted the user layer"

echo "install-env-tcsh: OK"
```
